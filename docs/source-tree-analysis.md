`cmd/scrapd` (service) and `cmd/scrapctl` (operator CLI); both are thin shells

## `internal/` Package Map

The composition root `internal/cmd` is the only package that wires the others
together; feature packages expose narrow options/interfaces rather than
importing each other directly.

| Package | Responsibility |
| --- | --- |
| `cmd` | **Composition root.** Config load/validate, startup security gates, telemetry, listeners, shard set, peer client/server, admin server, lifecycle (`App.Run`/`Shutdown`), healthcheck subcommand. |
| `server` | Public `DocumentService` gRPC handlers (write/head/read/find), health, per-request telemetry, authz/audit/rate-limit hooks. |
| `store` | `Store` interface (write/head/read/find) + typed error vocabulary (already-exists, not-found, resource-exhausted, unavailable, data-loss). Core boundary; no gRPC imports. |
| `shard` | **Per-shard orchestrator.** Write path (block + index writers), Raft apply handler, projection rebuild, scrub coordination, Backend upload, eviction, rewrap, quarantine. The `Store` implementation. (largest package, ~90 files) |
| `raft` | etcd/raft node wiring, StatefulSet ordinal discovery, K8s peer-set construction, gRPC raft transport. |
| `peer` | Inter-Member replication: peer gRPC client/server, streaming block transfer, projection rebuild, corrupt-block repair, quorum accounting, Raft forwarding. |
| `block` | On-disk append-only Block format: CRC-protected Frames, `.blk` writer/reader, sealed-block listing, `.idx` files, integrity verification, quarantine. |
| `localblock` | Per-Member local Block lifecycle: marker files, restart classification, crash-safe marker cleanup. |
| `index` | Pebble-backed metadata projection (transaction/document index) + pending-upload outbox. |
| `backend` | Durable object-store abstraction (filesystem + S3) behind one interface with shared error classification. |
| `encryption` | OpenBao Transit boundary for envelope encryption (real + deterministic fake). |
| `rewrap` | Bounded request/result/health contracts for durable envelope key-version updates. |
| `scrub` | Light scrub (cross-replica consistency) + deep scrub (on-disk frame verification + repair), I/O rate limiting, latency pausing, OTel metrics. |
| `avscan` | Content Scanner scheduling + engine boundaries (malware scan of sealed Blocks after ACK). |
| `quarantine` | Bounded Content Quarantine admin contracts. |
| `eviction` | Operator-facing eviction campaign contract (planner, apply, campaigns, redaction). |
| `routing` | Shard routing boundary: Transaction → fixed hash slot → Shard placement, bounded lookup records. |
| `security` | Shared security primitives: startup gates, TLS config, role/peer-identity policy, authz, audit, rate limits, production-readiness. |
| `audit` | Bounded security audit records + sink boundaries. |
| `admin` | Operator-facing admin HTTP server (health, metrics, eviction/rewrap/quarantine, pprof, test hooks). |
| `telemetry` | OpenTelemetry resources + instruments; identifier hashing mode; runtime/disk/raft attributes. |
| `logbridge` | Application slog logger + bridges to zap and etcd/raft logger. |
| `ulid` | ULID generation/parsing with configurable monotonic generator. |
| `scrapctl` | Operator CLI checks (doctor, status, upload-pressure, peers, leader, fault, evidence, eviction, quarantine, openbao). |
| `spike` | Phase 1 experimental write-path scaffold. **Not production**; excluded from lint baseline; must not be imported by production packages. |

## Entry Points

- **`cmd/scrapd/main.go`** — dispatches `healthcheck` subcommand or delegates to
  `internalcmd.Run(...)`; injects `version`/`buildSHA`/`buildTime` via ldflags.
- **`cmd/scrapctl/main.go`** — operator CLI delegating to `internal/scrapctl.Run`.
- **`internal/cmd/app.go` → `newApp` / `App.Run`** — the runtime composition root
  and serving loop (client gRPC + peer gRPC + admin HTTP).

## Compile-Time Dependency Direction (selected)

- `cmd` → everything (composition root only).
- `server` → `store` (transport maps to the storage boundary).
- `shard` → `scrub` → `{block, ulid}` (scrub defines ports; shard injects adapters).
- `shard` → `backend`, `shard` → `index`, `shard` → `block`.
- `peer` connects to shard behavior through narrow interfaces (`ReplicationSink`,
  `RebuildHandler`, `RaftRouter`) — it does not import `internal/shard`.
- Core storage/consensus packages must not import `grpc/status` / `grpc/codes`
  (enforced by `make package-boundaries`).
