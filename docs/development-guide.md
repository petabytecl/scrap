# Development Guide — S.C.R.A.P.

_Generated by the document-project workflow (exhaustive scan), 2026-06-21._

All commands are driven through the `Makefile`. Run `make help` for public
targets and `make help-vars` for overridable variables.

## Prerequisites

- **Go 1.26.4** (matches `go.mod` / `tools.go.mod`).
- **Docker** — Testcontainers-based integration tests, container builds, local
  `act` workflows.
- **kubectl** — Kubernetes-oriented targets.
- **GitHub CLI (`gh`)** — local `act` targets that need GitHub tokens.

Go-managed tools are pinned in `tools.go.mod` and invoked via
`go tool -modfile=tools.go.mod` by the Makefile (buf, golangci-lint, gotestsum,
govulncheck, kustomize). You do not install them globally.

## First Build

```sh
make build            # builds ./cmd/scrapd and ./cmd/scrapctl
```

## Protobuf

Protobuf under `proto/scrap/v1` is the source of truth; generated code lives in
`gen/go/` and must never be hand-edited.

```sh
make proto            # buf generate
make proto-check      # buf lint + generate + git diff --exit-code on gen/
```

## Formatting & Static Analysis

```sh
make fmt              # golangci-lint fmt (gofmt, gofumpt, goimports, gci)
make fmt-check        # diff-only check
make lint             # golangci-lint run (.golangci.yml is the executable contract)
make package-boundaries  # enforce core packages don't import grpc/status|codes, etc.
make static           # gates-check + kind-cilium-check + manifests-check + fmt-check + package-boundaries + proto-check + lint
```

Follow `docs/go-style-guide.md` for design/naming/errors/concurrency/tests;
`.golangci.yml` only covers the mechanical parts. Do not bypass linters with
local-only flags. `gen/` and `internal/spike/` are lint exclusions — do not copy
their style into production packages.

## Testing

Tests live next to code (`internal/<pkg>/*_test.go`) plus `test/integration`,
`test/e2e`, `test/stress`. Use the Go stdlib test stack (`testing`, `httptest`);
do not add testify/gomega/gomock without an ADR-level dependency decision.

```sh
make test             # go test ./...
make test-race        # go test -race ./...
make test-cover       # coverage profile + JUnit XML (excludes gen/ and internal/spike)
make integration      # go test -tags=integration ./test/integration/... (Testcontainers)
make vuln             # govulncheck ./...
```

Choose the **narrowest gate that proves the change**:

- `make test` — package logic.
- `make test-race` — concurrency / shared state.
- `make integration` — Pebble, Backend, persistence, local services
  (S3/LocalStack, OpenBao via Testcontainers).
- `make e2e-up` / `make tier2-e2e-up` — deployed gateway workflows.
- `make tier3-evidence-up` — telemetry/evidence/security/privacy claims.

A lower tier passing does not waive a higher tier when the changed behavior only
exists at that higher tier.

## Verification Gates (tiers)

```sh
make check            # static + tests + build (full local verification)
make tier1-check      # check + vuln (Tier 1 commit gate)
make tier2-e2e        # prod-like Kind E2E gate (requires an E2E Cell)
make tier3-evidence   # Tier 3 evidence gate (requires an evidence Cell)
```

## End-to-End locally

```sh
make e2e-up           # create Kind cluster, load image, deploy, run E2E tests
make e2e-down         # delete the local Kind E2E Cell
make e2e-scrub-up     # scrub-enabled E2E variant
```

## Local GitHub Actions (act)

```sh
make act-ci-validate            # validate ci.yml through act
make act-ci-job ACT_JOB=test    # run a single CI job
make act-ci                     # full workflow_dispatch path (cleans up on exit)
make act-ci-clean               # remove act containers + prod-like Kind Cell
```

## Configuration Reference

`scrapd` reads flags + environment in `internal/cmd/config.go`. Malformed env
values error out naming the key (no silent fallback).

### Flags

| Flag | Default | Purpose |
| --- | --- | --- |
| `--data-dir` | `/data` | storage root |
| `--listen-addr` | `:9090` | public gRPC |
| `--peer-addr` | `:9091` | peer gRPC |
| `--admin-addr` | `:8080` | admin HTTP |
| `--block-seal-size` | 64 MiB | Block seal threshold (accepts IEC suffixes) |
| `--peers` | — | dev override `1=host:9091,2=...` |

### Selected environment variables

| Variable | Purpose |
| --- | --- |
| `SCRAP_CELL_ID` | Cell identity (`local` defaults are non-production) |
| `SCRAP_REPLICAS`, `SCRAP_HEADLESS_SERVICE`, `SCRAP_PEER_PORT`, `POD_NAMESPACE` | K8s peer discovery |
| `SCRAP_SHARD_PLACEMENT_FILE` | multi-Shard placement map |
| `SCRAP_SECURITY_MODE` | security mode (e.g. `test`, production) |
| `SCRAP_TLS_{PUBLIC,PEER,ADMIN,SCRAPCTL}_{CERT,KEY,CLIENT_CA,SERVER_NAME}` | per-surface mTLS |
| `SCRAP_TRANSIT_{ADDR,MOUNT,KEY,TOKEN_ENV}`, `SCRAP_TRANSIT_FAKE` | OpenBao Transit |
| `SCRAP_ROLE_POLICY_FILE`, `SCRAP_PEER_IDENTITY_POLICY_FILE`, `SCRAP_AUDIT_POLICY_FILE`, `SCRAP_RATE_LIMIT_POLICY_FILE` | security policies |
| `SCRAP_UPLOAD_*` | Backend upload (enabled, concurrency, budget, pressure pcts) |
| `SCRAP_SCRUB_*`, `SCRAP_LIGHT/DEEP_SCRUB_*` | scrub tunables |
| `SCRAP_EVICTION_*` | Phase 4 eviction tunables |
| `SCRAP_TELEMETRY_RAW_IDS` | raw telemetry IDs (local non-prod only) |
| `SCRAP_TEST_HOOKS`, `SCRAP_PPROF_ENABLED` | dangerous surfaces (non-prod) |

Full default tables are in `CONTEXT.md`.

## Contribution Conventions

- Read `CONTEXT.md` first; use exact glossary terms (Document, Transaction,
  Block, Frame, Shard, Cell, Member, Backend) and avoid forbidden synonyms.
- Check `git status --short` before edits; preserve existing user intent.
- Production package work must trace to a PRD, story, accepted ADR, or GitHub
  issue before implementation. Create/update an ADR before changing storage
  format, wire protocol, dependency choices, security contracts, or cross-package
  boundaries.
- Behavior changes / bug fixes: add or update the failing test first.
- Commit messages: `<type>: <description>` (`feat`, `fix`, `refactor`, `docs`,
  `test`, `chore`, `perf`, `ci`); no agent attribution in bodies/trailers.
- Do not commit or push unless explicitly requested.
- BMAD artifacts live under `_bmad-output/`; promote only durable decisions into
  `docs/`. GitHub Issues are the external mirror (`docs/agents/issue-tracker.md`).
