# API Contracts — S.C.R.A.P.

_Generated by the document-project workflow (exhaustive scan), 2026-06-21._

S.C.R.A.P. exposes three surfaces, each on its own listener and network scope:

1. **Public gRPC** — `DocumentService` (client document operations).
2. **Peer gRPC** — `PeerService` (inter-Member replication / transfer / Raft).
3. **Admin HTTP** — operator/control-plane endpoints.

Protobuf is the source of truth under `proto/scrap/v1/`; regenerate Go with
`make proto`. The public/peer/admin boundaries are security-sensitive (ADR 0019,
ADR 0024) and must not be merged.

---

## 1. Public gRPC — `DocumentService`

Default listener: `:9090` (`--listen-addr`). Document identity is
`(transaction_id, document_name)`; `tenant_id` is accepted/validated but is not
part of storage identity.

| RPC | Shape | Description |
| --- | --- | --- |
| `WriteDocument` | client-stream → unary | Streamed write. First message `init` (metadata), then `chunk_data` frames. ACK only after Block bytes, `.idx`, peer quorum, and Raft metadata commit are durable. |
| `HeadDocument` | unary → unary | Metadata lookup (name, content type, size, SHA-256, created_at, scan status). |
| `ReadDocument` | unary → server-stream | Verified read. First `meta`, then `chunk_data`. All-or-error: corrupt reads send zero messages and return `DATA_LOSS`. |
| `FindDocuments` | unary → unary | Transaction-scoped list, returned in write order (ascending Block ID, then append order within each `.idx`). |

### Request/response messages

- `WriteDocumentRequest` — `oneof part { WriteDocumentInit init; bytes chunk_data }`.
  - `WriteDocumentInit`: `transaction_id`, `document_name`, `content_type`,
    `idempotency_key`, `tenant_id`.
- `WriteDocumentResponse`: `sha256_checksum` (lowercase hex), `size`, `created_at`.
- `ReadDocumentResponse` — `oneof part { ReadDocumentMeta meta; bytes chunk_data }`.
- `HeadDocumentResponse` / `DocumentMeta`: include `scan_status`
  (`ScanStatus`: UNSPECIFIED / CLEAN / QUARANTINED / UNSCANNED).
- `LeaderHint { leader_addr }` — attached as a gRPC status detail on
  `UNAVAILABLE` for non-leader members so the client can redirect (ADR 0024).

### Validation rules (boundary, exact-text preserving)

| Field | Rule |
| --- | --- |
| `transaction_id` | required, max 256 bytes |
| `document_name` | required, max 512 bytes |
| `content_type` | required, max 255 bytes |
| `tenant_id` | optional, max 256 bytes |
| `idempotency_key` | optional, max 256 bytes |

NUL/control characters rejected in text fields. Zero-byte Documents invalid.
Max client chunk: 1 MiB. Max Document: 128 MiB. Identifiers are never trimmed,
normalized, or case-folded.

### Error mapping (typed → gRPC status)

Store/server errors are typed and mapped centrally — **substring matching is
forbidden**: `ALREADY_EXISTS`, `NOT_FOUND`, `INVALID_ARGUMENT`,
`RESOURCE_EXHAUSTED`, `DATA_LOSS`, `UNAVAILABLE` (with `LeaderHint`),
`FAILED_PRECONDITION` (content-quarantined Document on `ReadDocument`).

### Resource controls

Default limits: 64 concurrent writes, 256 concurrent reads. Excess RPCs are
rejected immediately with `RESOURCE_EXHAUSTED`.

## 2. Peer gRPC — `PeerService`

Default listener: `:9091` (`--peer-addr`). Network-restricted to peers. Peer
authorization verifies role, Cell, Member identity, principal binding, and
configured Shard membership before any Shard-scoped handler runs (ADR 0024).

| RPC | Shape | Purpose |
| --- | --- | --- |
| `ReplicateDocument` | client-stream → unary | Hot-path write replication: leader pushes Document frames to a follower (init carries `shard_id`, block/offset/frame metadata, SHA-256, encryption envelope). |
| `TransferBlock` | unary → server-stream | Recovery path: transfer a sealed Block (`.blk` + `.idx`) to a new/lagging Member. |
| `ConsistencyCheck` | unary → unary | Light scrub: leader pulls a voter's projection SHA-256 at an applied index. |
| `RequestIndexRebuild` | unary → unary | Leader instructs a divergent voter to wipe + rebuild its projection from Raft state. |
| `ForwardRaft` | unary → unary | Forward a Raft message to the shard's Raft node. |
| `ForwardRaftStream` | bidi-stream | Streaming Raft message forwarding. |

## 3. Admin HTTP — `internal/admin`

Default listener: `:8080` (`--admin-addr`). Routes are registered conditionally
based on injected providers. Authorized endpoints gate on roles
(`RoleAdminReader`, `RoleAdminBreakGlass`).

| Method/Path | Auth | Purpose |
| --- | --- | --- |
| `GET /healthz` | open | Health/readiness reporting. |
| `GET /metrics` | `RoleAdminReader` | Prometheus/OTel metrics handler (when configured). |
| `POST /admin/eviction/plans` | admin | Create an eviction plan. |
| `GET/POST /admin/eviction/plans/{id}` and `/{id}/apply` | admin | Plan status / apply. |
| `POST /admin/rewrap/document` | admin | Durable envelope key-version rewrap. |
| `GET /admin/quarantine/documents` | admin | List Content Quarantine records. |
| `GET /admin/quarantine/document` | admin | Inspect one quarantine record. |
| `POST /admin/quarantine/confirm` | admin | Confirm (permanent) a quarantine. |
| `POST /admin/quarantine/release` | admin | Release (false positive) a quarantine. |
| `GET /debug/pprof/` (+ cmdline/symbol) | `RoleAdminReader` | Profiling index/symbol (GET-only; pprof disabled by default). |
| `GET /debug/pprof/profile`, `/trace` | `RoleAdminBreakGlass` | CPU/trace capture (break-glass). |
| `POST /test-hooks/projection-key` | test only | Inject a projection key (requires `SCRAP_TEST_HOOKS=1`). |
| `POST /test-hooks/transit-rotate` | test only | Rotate the fake Transit key. |
| `POST /test-hooks/light-scrub` | test only | Trigger a light scrub run. |

pprof and `/test-hooks/*` are dangerous surfaces: disabled by default,
network-restricted to telemetry collectors/operators, and forbidden in
production overlays (only prod-like E2E overlays may set `SCRAP_TEST_HOOKS=1`).

## 4. Operator CLI — `scrapctl`

Not a network API, but the operator-facing command surface
(`internal/scrapctl`). Subcommands:

```
scrapctl <doctor|status|upload-pressure|peers|leader|fault|evidence|eviction|quarantine|openbao>
```

Common flags include `--namespace`, `--cluster`, `--context`, `--admin-url`,
`--metrics-url`, `--client-addr`, `--admin-addr`, `--timeout`, `--output text|json`,
and mTLS client flags (`--tls-cert`, `--tls-key`, `--tls-ca`, `--tls-server-name`).

## Compatibility Guarantees

7-year retention forces long-lived wire compatibility (`CONTEXT.md`):

- **Proto:** fields added, never removed/renumbered; no type changes without a
  major version bump; 2-release deprecation notice before zeroing.
- A Document written with schema version N must be readable by software version
  N+5 or later.
- SHA-256 is exposed on the wire as lowercase 64-char hex; stored internally as
  raw 32-byte digests.
