# Data Models — S.C.R.A.P.

_Generated by the document-project workflow (exhaustive scan), 2026-06-21._

S.C.R.A.P. has no relational database. Its "data models" are three serialized,
long-lived contract layers plus the derived Pebble Projection:

1. **On-disk Block format** (`.blk` Frames + `.idx` index) — `internal/block`.
2. **Raft log commands** (`RaftCommand` oneof) — `proto/scrap/v1/raft.proto`.
3. **Pebble Projection** (derived metadata index) — `internal/index`.

Authority rule: **Raft metadata is the source of truth** for Document
visibility and physical references; the Pebble Projection is fully rebuildable
from Raft log replay + Block bytes. Document bytes never enter Raft (ADR 0001).

---

## 1. On-Disk Block Format (ADR 0002, 0003)

A **Block** is an append-only file containing multiple Documents as sequential
**Frames**, sealed at a size threshold (default 64 MiB). Block IDs are `uint64`
rendered as fixed-width lowercase hex: `000000000000002a.blk` / `.idx`. Seals
happen between Documents, never mid-Document. Restart always opens a new Block.

### Block header (40 bytes, little-endian)

```
magic(4) + version(2) + header_len(2) + shard_id(8) + block_id(8) +
created_at_unix_micro(8) + reserved(4) + header_crc32c(4)
```
`header_crc32c` covers bytes 0–35. Readers validate header CRC and
filename/header Block-ID agreement.

### Frame header (32 bytes, little-endian)

```
magic(2) + version(1) + flags(1) + header_len(2) + reserved(2) + doc_seq(4) +
frame_seq(4) + payload_len(4) + payload_crc32c(4) + reserved(4) + header_crc32c(4)
```
`header_crc32c` covers bytes 0–27. Payload CRC uses CRC-32C (Castagnoli).
Max Frame payload: 64 KiB — the unit of checksum verification.

### `.idx` index file

CRC-protected `SIDX` header. Each entry is framed as
`entry_len + payload + entry_crc32c`. Entry payload includes: version, reserved,
transaction ID, document name, content type, created_at, first frame offset,
frame count, total bytes, raw SHA-256 digest. `HeadDocument` and `FindDocuments`
fail closed on `.idx` CRC/header/entry corruption.

### Checksums (dual, ADR 0002)

- **CRC-32C per Frame** — enables safe ranged reads.
- **SHA-256 per Document** — whole-Document integrity; stored raw (32 bytes).

## 2. Raft Log Commands (`proto/scrap/v1/raft.proto`)

`RaftCommand` wraps a `oneof command` (~330 bytes/document) plus W3C trace
context (`traceparent`/`tracestate`, ADR 0013) carried for traceable apply on
all replicas.

| Command | Fields (selected) | Purpose |
| --- | --- | --- |
| `CommitDocument` | tx id, doc name, content type, idempotency key, block id, first frame offset, frame count, total bytes, sha256, created_at_us, encryption_envelope | Commit Document metadata → visibility (apply-side conflict detection, first-writer-wins). |
| `SealBlock` | block id, shard id, sealed_size_bytes, sealed_at_us | Seal a Block; materializes an Upload Outbox obligation. |
| `ConfirmUpload` | block id, shard id, confirmed_at_us, `block_object`, `index_object` (BackendObjectMetadata: key/size/validation_token), upload_generation | Record verified Backend upload of `.blk` + `.idx` (ADR 0010). Fields 3/5 reserved (legacy `backend_key_prefix`/`etag`). |
| `RewrapDocumentEnvelope` | tx id, doc name, block id, encryption_envelope, old/new key version, rewrapped_at_us, proposal_id | Durable, idempotent envelope key-version update (ADR 0021). |
| `QuarantineDocument` | tx id, doc name, block id, detected_at_us, scan_type, reason | Content Scanner flags a Document (ADR 0025). |
| `ConfirmQuarantine` / `ReleaseQuarantine` | tx id, doc name, timestamp, proposal_id | Operator confirm/release of a Content Quarantine. |
| `RequestConsistencyCheck` | scrub_id, requested_at_us | Light scrub trigger across voters. |

Enums: `QuarantineScanType` (UNSPECIFIED/INITIAL/RESCAN),
`QuarantineReason` (UNSPECIFIED/SCANNER_DETECTION).

### Openlog entry (crash-recovery intent record)

`OpenlogEntry { transaction_id, document_name, block_id, start_offset,
content_type, idempotency_key }` — written as `{write_id}.prep` (ULID-named,
~200–300 bytes) before bytes commit. Recovery scans `.prep` files in ULID order:
if Raft committed the Document, delete the `.prep`; otherwise truncate the Block
at `start_offset` and delete (partial write).

## 3. Pebble Projection (derived, ADR 0004, 0011)

Lean per-Transaction keys (Option D): `transaction_id` →
`{block_ids, doc_count, completed}`. A Transaction may span multiple Blocks, so
`block_ids` is a list. Per-Document resolution walks the Block `.idx` files
(Projection Resolution). Strict client reads fail closed on visible metadata
corruption; ADR 0014 lenient resolution is for recovery/replay only.

- **Key schema:** 1-byte version prefix on every key
  (`PebbleKeySchemaV1 = 0x01`); legacy unversioned keys detected on open.
- **Dedicated key prefixes** (ADR 0011) separate: transaction projection,
  upload outbox, confirmed upload catalog, content-quarantine identities,
  scrub progress watermarks.
- **Metadata tiering:** configurable hot window (default 6 months); evicted
  entries → monthly catalog archives on the Backend with per-month bloom filters
  for deterministic cold lookup.

---

## 4. Backend Object Model (ADR 0009)

Sealed Blocks upload as **two separate objects** (`.blk` and `.idx`):

```
{cell_id}/shards/{shard_id}/{block_id}.blk
{cell_id}/shards/{shard_id}/{block_id}.idx
```

Provider-neutral error taxonomy keys retry/admission decisions:
`throttled`, `transient`, `auth`, `not-found`, `conflict`, `corrupt`,
`permanent`.

---

## 5. Member Identity Model

Three-level identity (never conflate):

| Level | Source | Lifetime |
| --- | --- | --- |
| `cell_id` | operator config | permanent for the deployment |
| `member_hostname` | K8s pod hostname | StatefulSet slot lifetime |
| `member_id` | durable record on the PVC | data-volume lifetime |

Stored at `/data/identity/member.json`. Local non-production mode may default
`cell_id=local, member_id=local`, which must stay visibly marked and must not
satisfy production ACK/peer/admin gates.

## Filesystem Layout

```
/data/
├── identity/member.json
├── shards/{shard_id}/
│   ├── raft/{wal/, snap/}          # etcd WAL + snap libraries
│   ├── pebble/                     # Projection KV
│   ├── blocks/{block_id}.blk,.idx  # Block bytes + index
│   └── openlog/{write_id}.prep     # crash-recovery intent records
└── tmp/
```
